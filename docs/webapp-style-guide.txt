1. COLOR PALETTE
--------------------------------------------------------------------------------

TOKEN                              HEX        TAILWIND   USE

                                                         headings, status dots, focus rings
opta-green-hover                   #00a344    --         Primary hover (or just opacity-90)
industrial-bg                      #030712    gray-950   Page background, code chips
industrial-panel                   #111827    gray-900   Cards, tab bar, dropdown menus

HEADER / FOOTER EXCEPTION
  The top <header> and <footer> use a slightly lighter slate than the panels:

    border     : border-slate-600  (border-b on header, border-t on footer)
    text       : text-slate-300
  Plus a 1px full-height accent bar down the left edge:
    <div class="absolute top-0 left-0 w-1 h-full bg-industrial-primary"></div>

2. TYPOGRAPHY
--------------------------------------------------------------------------------

FONT STACKS (Google Fonts: Inter, Outfit, JetBrains Mono)
  --font-sans:    "Inter", ui-sans-serif, system-ui, sans-serif        (body)
  --font-display: "Outfit", sans-serif                                 (available, sparse use)
  --font-mono:    "JetBrains Mono", ui-monospace, SFMono-Regular, monospace  (numbers, codes, footer)

Body: bg-industrial-bg text-industrial-text font-sans antialiased

HEADINGS / SECTION LABELS  — tiny and wide
  size      text-xs   (often text-[10px] / text-[11px])
  weight    font-bold
  case      uppercase
  tracking  tracking-[0.2em]   (tabs: tracking-[0.18em]  buttons: tracking-widest
                                footer: tracking-[0.3em])
  color     text-industrial-primary  or  text-industrial-muted

NUMERIC VALUES
  font-mono  text-xl  font-bold   color by meaning (primary / blue-400 / orange-400 / white)

BODY COPY
  text-xs  leading-relaxed  text-industrial-muted

--------------------------------------------------------------------------------
3. TAILWIND v4 @theme BLOCK (src/index.css)
--------------------------------------------------------------------------------

@import url('https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600;700&family=JetBrains+Mono:wght@400;700&family=Outfit:wght@400;500;600&display=swap');
@import "tailwindcss";

@theme {
  --font-sans: "Inter", ui-sans-serif, system-ui, sans-serif;
  --font-display: "Outfit", sans-serif;
  --font-mono: "JetBrains Mono", ui-monospace, SFMono-Regular, monospace;

  --color-industrial-primary: #00C853;
  --color-industrial-bg: #030712;      /* gray-950 */
  --color-industrial-panel: #111827;   /* gray-900 */
  --color-industrial-input: #1f2937;   /* gray-800 */
  --color-industrial-border: #374151;  /* gray-700 */
  --color-industrial-text: #f3f4f6;    /* gray-100 */
  --color-industrial-muted: #9ca3af;   /* gray-400 */

  --color-opta-green: #00C853;
  --color-opta-green-hover: #00a344;
}

@layer base {
  body {
    @apply bg-industrial-bg text-industrial-text font-sans antialiased;
  }
}

4. COMPONENT RECIPES (src/index.css utility classes)
--------------------------------------------------------------------------------

/* Surface / card */
.industrial-card {
  @apply bg-industrial-panel border border-industrial-border rounded shadow-lg transition-all;
}

/* Text input */
.industrial-input {
  @apply w-full bg-industrial-input border border-industrial-border px-3 py-2 text-sm text-white
         focus:outline-hidden focus:border-industrial-primary
         focus:ring-1 focus:ring-industrial-primary/20 rounded transition-colors;
}

/* Buttons — shared base */
.industrial-button-base {
  @apply px-4 py-2 text-xs font-semibold uppercase tracking-widest transition-all cursor-pointer
         disabled:opacity-50 disabled:cursor-not-allowed rounded shadow-sm;
}

/* Primary button = base + */
.industrial-button-primary {
  @apply bg-industrial-primary text-black hover:opacity-90
         shadow-[0_0_15px_rgba(0,200,83,0.2)];
}

/* Secondary button = base + */
.industrial-button-secondary {
  @apply bg-transparent border border-industrial-border text-industrial-muted
         hover:border-industrial-muted hover:text-white;
}

/* Danger button = base + */
.industrial-button-danger {
  @apply bg-red-900/40 text-red-100 border border-red-900/50 hover:bg-red-900/60;
}

/* Status dot */
.status-indicator {
  @apply w-4 h-4 rounded-full inline-block shadow-[0_0_12px_rgba(0,200,83,0.8)];
}

--------------------------------------------------------------------------------
6. CONVENTIONS AT A GLANCE
--------------------------------------------------------------------------------

CORNERS   rounded (4px) almost everywhere;  rounded-lg only on popover menus
BORDERS   1px solid industrial-border;  emphasis via border-l-4 border-l-industrial-primary
SHADOWS   shadow-lg on cards, shadow-xl on popovers, green glow on accent elements
ICONS     lucide-react — 13-16px inline, 24px in feature tiles;
          color text-industrial-muted (default) or text-industrial-primary (accent)
MOTION    motion/react for menus & feedback; fast (duration 0.1), small y-offset (-4px),
          height auto-animate for expanding banners
FOCUS     focus:border-industrial-primary + focus:ring-1 focus:ring-industrial-primary/20
DISABLED  disabled:opacity-50 disabled:cursor-not-allowed
UPPERCASE nearly every label/heading/button is uppercase with wide letter-spacing
